# Spec Delta

## MODIFIED Requirements

### Requirement: 教師管理自己的課程與課程清單
系統 SHALL 允許已登入教師建立、命名、查看自己的課程，並將可用講義版本加入課程活動清單；非示範模式只能加入在該課程匯入的講義版本，`GUIDED_NOTES_DEMO_CATALOG=1` 時可加入示範清單。教師只能操作自己的課程，建立活動時 SHALL 固定該課程選定的講義版本與題目識別。（D04、D11、D12／FR-001、D15）

#### Scenario: 建立並查看課程
- **WHEN** 已登入教師建立並命名課程
- **THEN** 該課程出現在此教師的課程列表與課程頁

#### Scenario: 加入可存取清單並建立活動
- **WHEN** 教師將 notes 可存取的指定清單版本加入自己的課程
- **THEN** 建立活動時只能從該課程已加入的清單版本選擇，且活動固定該版本及其題目識別

#### Scenario: 阻擋他人課程操作
- **WHEN** 教師嘗試讀取或操作另一位教師的課程、課堂或活動
- **THEN** 系統拒絕請求且不洩漏資源內容或是否存在

#### Scenario: 課程清單只顯示本課程匯入的講義
- **WHEN** 教師在非示範模式查看自己的一門課程，且教師已在該課程匯入講義版本
- **THEN** 課程頁的可用清單只包含該課程已匯入的講義版本，不顯示教師其他課程的版本

#### Scenario: 拒絕加入其他課程的講義版本
- **WHEN** 教師將只屬於課程 X 的講義版本識別提交至課程 Y 加入
- **THEN** 系統拒絕加入且不揭露課程 X 或該版本的資料

#### Scenario: 示範模式可加入示範清單並建立活動
- **WHEN** 示範模式下教師查看自己的課程頁
- **THEN** 可用清單包含示範清單，加入後可建立固定版本的活動

## ADDED Requirements

### Requirement: notes 課程操作依 activities 課程授權
notes SHALL 依 activities 的教師課程所有權授權課程範圍查詢、匯入及保存操作；無效或未授權課程均以 `COURSE_FORBIDDEN` 拒絕且不洩漏課程是否存在。（D04、D15）

#### Scenario: 教師存取自己的講義匯入頁
- **WHEN** 已登入教師開啟自己課程的講義管理頁
- **THEN** 系統授權存取課程範圍講義功能，且不回報 `NOTES_INTEGRATION_PENDING`

#### Scenario: 拒絕他人或不存在的課程
- **WHEN** 教師開啟另一位教師的課程或不存在的課程之講義管理頁
- **THEN** 系統以相同的 `COURSE_FORBIDDEN` 錯誤拒絕請求，不回傳課程或講義資料

### Requirement: 教師可從課程頁開啟及返回講義管理
系統 SHALL 提供從活動課程頁進入該課程講義管理頁的入口，並讓教師從講義管理頁返回其活動課程頁。（D15）

#### Scenario: 從課程頁進入講義管理
- **WHEN** 已登入教師查看自己的活動課程頁
- **THEN** 頁面提供文字為「匯入／管理講義」且連到同一課程講義管理頁的入口

#### Scenario: 從講義管理返回活動課程
- **WHEN** 已授權教師查看課程的 notes 講義管理頁
- **THEN** 頁面提供「回課程頁」連結，指向同一課程的活動課程頁

### Requirement: notes 瀏覽器頁面以中文錯誤頁呈現錯誤
notes 瀏覽器頁面發生可預期錯誤時，系統 SHALL 顯示包含中文訊息、錯誤代碼及適當返回連結的 HTML 錯誤頁，並保留原 HTTP 狀態碼；`/api/` 路徑 SHALL 維持 JSON 錯誤格式。（D04、D15；本組自行決定）

#### Scenario: 拒絕未授權課程時返回課程列表
- **WHEN** 教師因 `COURSE_FORBIDDEN` 無法存取 notes 課程頁
- **THEN** 系統回傳中文 HTML 錯誤頁及原 HTTP 狀態碼，包含錯誤代碼與返回教師課程列表的連結

#### Scenario: 其他 notes 頁面錯誤返回已授權課程
- **WHEN** notes 瀏覽器頁面因來源連結無效或 Google 憑證未設定等錯誤拒絕請求，且教師仍擁有該 `course_id`
- **THEN** 系統回傳中文 HTML 錯誤頁及原 HTTP 狀態碼，包含錯誤代碼與返回該課程 notes 講義管理頁的連結

#### Scenario: API 錯誤維持 JSON
- **WHEN** `/api/` 路徑發生可預期錯誤
- **THEN** 系統以原 HTTP 狀態碼回傳包含錯誤代碼與訊息的 JSON

#### Scenario: notes 頁自行顯示的操作結果維持原樣
- **WHEN** notes 頁面以既有頁面內容呈現匯入、回填或預覽結果
- **THEN** 系統維持該頁面的既有結果呈現，不改以共用錯誤頁取代

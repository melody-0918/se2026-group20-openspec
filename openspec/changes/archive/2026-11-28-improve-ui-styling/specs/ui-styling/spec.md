# Spec Delta

## Purpose

提供一致、易讀且適合投影與錄影的使用者介面呈現，讓不同頁面的資訊層級與狀態辨識方式一致。（本組自行決定）

## ADDED Requirements

### Requirement: 使用者頁面載入共用本機樣式
所有使用者可瀏覽的 HTML 頁面 SHALL 載入同一份由應用程式本機提供的共用樣式檔。（本組自行決定）

#### Scenario: 開啟任一使用者頁面
- **WHEN** 使用者開啟首頁、登入、教師、課程、課堂、加入、學生、notes 或錯誤頁面
- **THEN** 該頁面引用共用樣式檔，且該靜態檔可由應用程式正常取得

### Requirement: 狀態資訊以文字標示
頁面 SHALL 以可讀文字標示活動階段、課堂狀態及勝組；顏色 SHALL 僅作為輔助辨識。（本組自行決定）

#### Scenario: 顯示學生活動階段
- **WHEN** 學生頁顯示準備中、搶答中或已結束階段
- **THEN** 頁面以對應文字呈現階段，且不需依賴顏色判斷

#### Scenario: 顯示教師作答結果
- **WHEN** 教師課堂頁顯示已結算題目的勝組
- **THEN** 勝組有清楚的文字標示，且不需依賴顏色判斷

### Requirement: 樣式不依賴外部來源
使用者頁面的樣式 SHALL 由本機資源提供，不得依賴外部 CSS 框架、CDN 或網路字體。（本組自行決定）

#### Scenario: 離線載入使用者頁面
- **WHEN** 使用者在沒有外部網路連線的本機環境開啟使用者頁面
- **THEN** 共用樣式仍可載入，且頁面樣式不需連線至外部 CSS、CDN 或網路字體來源

# Spec Delta

## MODIFIED Requirements

### Requirement: 學生與教師取得受權限限制的權威狀態
系統 SHALL 提供教師與學生查詢課堂及活動狀態的能力；學生回應可包含活動固定版本的題目與小題顯示文字，但只限該學生所屬課堂與組別，不包含其他組資訊或來源答案。（R08、D03、D04、D09、D14、D19、D22（取代 D16）、本組決定）

#### Scenario: 目前活動選取順序
- **WHEN** 系統為學生選取課堂目前活動
- **THEN** 依序選取搶答中的活動、最新建立的準備中活動、最近結束的活動；三者皆無才顯示等候狀態

#### Scenario: 加入時沒有任何活動
- **WHEN** 學生加入的課堂尚無搶答中、準備中或已結束活動
- **THEN** 學生頁顯示等候狀態，教師開始活動後學生頁自動顯示該活動

#### Scenario: 學生查看目前活動
- **WHEN** 學生輪詢自己的課堂狀態
- **THEN** 回應含課堂名稱、自己的組名、目前活動名稱、活動階段、題號及活動固定版本提供的題目與小題顯示文字，不含其他組資訊或來源答案

#### Scenario: 準備中學生可看題但不能作答
- **WHEN** 學生查看準備中的活動
- **THEN** 頁面顯示題號、固定版本題目文字，以及題組小題標號與小題文字，內容唯讀且不顯示輸入框

#### Scenario: 學生自動切換活動
- **WHEN** 教師結束舊活動並開始同堂新活動
- **THEN** 學生在目標 2 秒內看到新活動狀態與題號，且仍屬原組別

#### Scenario: 活動結束後顯示最近結束活動
- **WHEN** 教師結束目前活動，且下一個活動尚未開始、也沒有準備中的活動
- **THEN** 學生頁顯示最近結束活動的名稱、「已結束」階段及題號，不回到等候狀態

#### Scenario: 準備中活動優先於最近結束活動
- **WHEN** 課堂有最近結束的活動及一個或多個準備中活動，且沒有搶答中活動
- **THEN** 學生頁顯示最新建立的準備中活動及其題號

#### Scenario: 關課後查看課堂與目前選取活動狀態
- **WHEN** 課堂已關閉，且學生持有有效加入證明查詢狀態
- **THEN** 學生頁只顯示「課堂已結束」，不顯示活動、題號或任何結果（D22（取代 D16）、本組決定）

#### Scenario: 忽略較舊狀態回應
- **WHEN** 前端收到狀態版本較目前顯示版本舊的輪詢回應
- **THEN** 前端不套用該回應，畫面狀態不倒退

#### Scenario: 搶答前後學生資訊隔離
- **WHEN** 學生於任何活動階段取得狀態
- **THEN** 回應皆不包含其他組別的識別、加入狀態或資料

## ADDED Requirements

### Requirement: 教師查看活動識別及 Guided Notes 回填入口
教師課堂頁 SHALL 在已結束活動旁顯示其活動識別碼及通往該課程 Notes 頁面的回填入口。（D06、D11、本組自行決定）

#### Scenario: 已結束活動顯示回填入口
- **WHEN** 教師查看仍開放或已關閉課堂內的已結束活動
- **THEN** 頁面顯示活動識別碼及連到該課程 Guided Notes 頁面的入口

#### Scenario: 尚未結束活動不顯示回填入口
- **WHEN** 教師查看準備中或搶答中的活動
- **THEN** 頁面不顯示該活動的回填入口

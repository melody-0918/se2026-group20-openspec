## 3. 匯入、解析、預覽與版本

- [x] 3.1 實作動態表頭、正整數主題號和單題答案格辨識。驗證方式為使用欄列位置不同或含合併格的測試資料，確認顯示為 `1` 的 `1.4` 不會形成題號、合法題號 `01` 保留原樣，以及涵蓋整題的跨列答案只寫入錨點。檢查缺少或重複表頭、跨題答案與歧義的拒絕行為。
- [x] 3.2 依主題號的合併範圍辨識題組和作答格，保留半形、全形與括號內空白，擷取題目欄文字。驗證方式為測試混合版面的三種計數、空白分隔列、小題續行與作答格定位，並驗證課程明細的文字與固定版本一致，且未讀入來源作答格內容。
- [ ] 3.3 接入正式 B 課程授權與活動選用，使用 A 已提供的 `list_course_catalogs()` 及 `get_course_catalog()`。驗證方式為以不同教師與課程檢查清單、精確版本、預覽和保存隔離；確認未保存預覽不列入、保存失敗不留部分資料、新版保留舊版，且建立活動只固定該課程的合法版本。上述 A 行為已用替身驗證，正式接入後再重驗。
- [x] 3.4 以正式 SQLite 資料驗證 `list_available_catalogs(teacher_id)` 和 `get_catalog(teacher_id, import_id, import_version)`。驗證方式為比較摘要、明細與 Foundation 既有欄位，核對單題恰有一個 item、題組的 `label`／`order` 與來源一致，以及保存新版並重新載入後舊版的 `question_id`、`item_id`、`display_number` 和順序不變。確認未回傳作答格內容、格位或憑證。
- [x] 3.5 驗證兩個查詢的教師隔離、精確版本與示範相容性。驗證方式為以兩位教師及不同版本核對清單可見範圍，斷言其他教師的清單、未知講義或未知版本均回相同 `CATALOG_NOT_FOUND`（404），且不回傳其他版本；無效教師查詢皆回 `TEACHER_REQUIRED`（401）。另在隔離測試中啟用示範旗標，確認既有示範資料仍可讀。

## 4. 結算後回填、重檢與恢復

- [ ] 4.1 接入由 B `get_ended_snapshot()` 轉成的已結算快照，檢查歷史活動權限、固定課程與版本、題目、勝組和完整答案。驗證方式為以正式 B 資料重驗已結束未結算、活動或課程未授權、錯誤版本、缺漏或重複識別、無勝組及同一勝組的完整題組答案；拒絕情境不得觸發 Sheets 寫入。A 現已透過測試替身覆蓋對應分支。
- [x] 4.2 產生回填預覽，確認前重查來源位置、題目和目標格的原值及顯示文字。驗證方式為模擬移動欄列、改原值或顯示文字及移除一題。依序核對 `SOURCE_PREVIEW_STALE`、新版預覽與 `SOURCE_REIMPORT_REQUIRED`，確認舊計畫不會寫入或改綁活動。
- [x] 4.3 僅寫目標答案格，加入逐格回讀及續填，保留小題標號、合併格式及原勝組。驗證方式為模擬回讀不符、回應中斷、部分完成和他人改值，核對 HTTP `WRITEBACK_CONFLICT`、`SHEETS_WRITE_UNVERIFIED` 與逐格回填狀態，檢查已完成格未重寫，只有安全的未完成格可續寫。
